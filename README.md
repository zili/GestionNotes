# GestionNotes

Application console C# (.NET 10) de gestion des notes pour 4 étudiants (programmation orientée objet).

## Fonctionnalités
- Saisie des noms des 4 étudiants
- Saisie des notes (nombre illimité, ligne vide pour terminer)
- Calcul de la moyenne
- Classement et affichage par ordre de classement

## Classes
- `Etudiant` : nom, notes, rang, calcul de la moyenne
- `Classe` : tableau d'étudiants, tri et classement
- `Program` : saisie et affichage

## Exécution
```bash
dotnet run
```
